

# Data Analyzer And Transformer Program

## Subtitle
A Python-based menu-driven program for analyzing, transforming, filtering, sorting, and calculating statistics from numerical data.

# How To Use

1. Run the Python program.
2. Select an option from the Main Menu.

```
1. Input Data
2. Display Data Summary
3. Calculate Factorial (Recursion)
4. Filter Data By Threshold
5. Sort Data
6. Display Dataset Statistics
7. Exit Program
```

3. Enter your choice.
4. Provide required data input.
5. View the generated output.

---

# Installation

### Step 1: Install Python

Download and install Python from:

```
https://www.python.org/
```

### Step 2: Clone or Download Project

Download the project files into your system.

### Step 3: Run Program

Open terminal:

```
python main.py
```
